  • Average reduction: 22.3% (95% CI: 13.1% - 32.5%)
  • Effect is highly significant (P = 0.0005)

  3. Includes meteorological confounders
  4. Uses robust covariance estimation

Outcome variable: norway_aval_count
  - Definition: Daily count of avalanche events in Norwegian Alps
  - Range: 2 to 40 events per day
  - Mean: 7.23, Median: 2, Std Dev: 9.50
  - Highly right-skewed with overdispersion

Exposure variable: ssw_within_15d
  - Definition: Binary indicator (1 = SSW occurred in prior 15 days, 0 = no SSW)
  - Frequency: 465 days with SSW (14.6%) vs 2,711 days without (85.4%)
  - Baseline avalanche rate: 7.87 events/day (no SSW)
  - SSW-exposed avalanche rate: 3.46 events/day

Grouping variable: winter_id
  - 21 distinct winter seasons (1998/99 through 2015/16)
  - Balanced observations (151-152 days per winter)
  - Each winter is Nov-Apr (winter semester)

Covariates:
  - z500_standardized: Standardized 500-hPa geopotential height anomaly
    Effect: Negative (higher height = fewer avalanches, p < 0.001)
    Suggests stronger polar vortex protective effect
  
  - precip_standardized: Standardized mean precipitation from SNOTEL stations
    Effect: Positive (higher precip = more avalanches, p < 0.001)
    Expected: More snow = more potential for avalanching

Estimation method: Generalized Estimating Equations (GEE)
  - Handles correlated observations within winters
  - Exchangeable correlation structure (common for repeated measures)
  - Robust sandwich covariance estimator (Huber-White)
  - Negative Binomial family (NB2 parameterization)

Model fit statistics:
  - AIC: 19,417 (GEE NB2)
  - AIC: 18,902 (GLM NB2 - note: lower AIC but biased)
  - Convergence: Achieved after 43 iterations (GEE NB2)
  - Scale parameter: 1.0 (fixed for NB2)

Confidence intervals: 95% using normal approximation (z-critical = 1.96)
