# Failures

Approaches that failed in ways that can recur. Read before resuming work on anything here.
Four lines each. Full scientific record of withdrawn claims is `ssw-design-analysis/CONSOLIDATED_RESULTS.md` §7.

## 2026-07-28 — Bootstrap seeded from `hash(str)`
Tried: `hash("aao") % 10000` to give each outcome a stable bootstrap seed.
Failed: Python randomises string hashing per process, so three runs gave 3533 / 7014 / 6074 and no p-value in three scripts was reproducible; a negative control "changed" from pass to fail on a byte-identical event set.
Rule: seed with `zlib.crc32(name.encode()) % N`. Before believing any change in a bootstrap result, confirm the seed and the input set both held fixed.

## 2026-07-28 — Intervals from too few bootstrap replicates
Tried: percentile CIs from 150–800 winter-block replicates.
Failed: at 150 reps each tail is estimated from ~4 order statistics; coverage 0.920 / FPR 0.080 against 0.947 / 0.053 on the same data and draws at 1,000.
Rule: N_BOOT ≥ 1000 for any reported CI or p-value; several thousand for a claim that crosses a significance threshold (at p≈0.05, 1,200 reps carry MC SE ≈ 0.009).

## 2026-07-28 — Contamination in the comparison group
Tried: three successive "fixes" to the pseudo-onset null, each repairing the previous one.
Failed: single-window designs put the post-onset response into the control days; drawing fake events only from SSW-hosting winters put the real signal in the null (−0.267 vs +0.006); excluding fake onsets from event zones left real depressed periods in the *baseline* (+0.234, 43% of baseline days contaminated).
Rule: before trusting any null, ask what is in the reference category, not only what is in the treatment window. Delete real-event-influenced days from the data entirely, then draw.

## 2026-07-30 — Negative control judged against the wrong FDR family
Tried: pooling the AAO control's 8 bins with AO/NAO/PNA into one 32-test BH family.
Failed: the positives' small p-values raise the BH threshold and make the *control* easier to call significant — backwards. q=0.036 pooled, q=0.13 on its own 8 bins. Cost a full investigation (60 seeds, bootstrap calibration, ENSO acquisition) to discover it was multiple testing.
Rule: a negative control is judged against its own family. Also reject "zero bins at raw p<0.05" as a pass criterion — with 4 bins that fails 18.5% of the time on pure noise.

## 2026-07-30 — Comparing an SE against a null SD from a different amount of data
Tried: bootstrap SE from the full record vs pseudo-onset null SD from the clean subset, to test whether the field's bootstrap is anti-conservative.
Failed: pure sample size. √(13864/8862) = 1.251 and the observed ratio was exactly 1/1.251. Nearly became a headline finding because the direction was plausible.
Rule: for calibration, fit the estimate *and* its interval on each null draw, then compare mean interval width to the SD of the estimates across draws. Anything else confounds calibration with sample size.

## 2026-08-01 — Calibrating a statistic against the wrong reference distribution
Tried: calibrating a dip-like statistic against a uniform, which is correct for Hartigan's exact dip.
Failed: the implementation measures distance to a *monotone* density, so any Gaussian scores ~0.25 and uniform calibration guarantees p≈0. Returned "BIMODAL, p=0.0000" at n=1888; recalibrating against resampled pseudo-events gave p=0.846 — the opposite conclusion.
Rule: calibrate against the null your own statistic actually has, generated by resampling your own data. Three tests that can disagree is what exposed this; a single-test design would have published the artefact.

## 2026-08-03 — Validation that simulates too narrow a family
Tried: validating the R diagnostic by simulating whole-winter depression (f=0) and post-onset depression (f=1), concluding "bias ≤ 0.047 across f ∈ [0,1]".
Failed: it never simulated a *precursor*. R returns ≈1 for an anomaly placed before onset, whose causal fraction is zero by construction, so the causal reading survived for months inside a validation that could not test it.
Rule: a validation licenses a claim only over the structures it simulates. Enumerate the structures the claim must exclude, and simulate each — especially the one that would break it.

## 2026-08-03 — Pooling ensemble members into a date-indexed frame
Tried: concatenating 10 CanESM5 members into one frame keyed by date, then selecting each event window by date.
Failed: members of one model share the calendar, so every window pulled rows from all ten, only one of which had the SSW. Diluted the composite 3.5× (−0.203 vs the correct −0.716) and made the model look unlike observations.
Rule: never select by date across pooled ensemble members. Pool *pairs* per member, as `multimodel_R.py` does.

## 2026-08-03 — Ratios and shares with an unmatched or near-zero denominator
Tried: implied R² = q(1−q)C²/Var for published contrasts; a "% of observed" ratio for a near-zero effect.
Failed: dividing an *observational* contrast by the *CMIP6* variance returned R² = 1.2852, an impossible value; and a 0.098 σ effect in the denominator produced a meaningless "412%".
Rule: numerator and denominator must come from the same system. Before quoting a ratio, check the denominator is both matched and not near zero — an impossible value is the giveaway, so look for one.

## 2026-08-04 — Running the flawed member of a script pair
Tried: closing Gate 3 by re-running `finalise_gate3.py`, the script whose name implies it is final.
Failed: it is the script `FINDING_gate3_contamination.md` labels flawed — its `excluded` draw leaves real events in the baseline, null +0.29. The corrected one, `gate3_clean_null.py`, shipped at N_BOOT=150, so every artifact said `passes=False` while three documents said CLOSED. No artifact supported the closure.
Rule: when two scripts answer one question, delete or rename the dead one. A file named `*_final.py` is not evidence that it is.

## 2026-09-17 — Every frozen artifact fails a byte comparison on Linux
Tried: re-running `build_catalogue.py` and `ensemble_precursor.py` on Linux to confirm they reproduce byte-for-byte.
Failed: nothing reproduced. Every artifact in this repo was written on Windows, where text-mode writes translate `\n` to `\r\n` — `event_catalogue.csv` came back 7,894 bytes against 7,943, `ensemble_precursor_CanESM5.json` 1,590 against 1,692 — while `DataFrame.equals` and parsed-JSON equality were both True and all invariance tests passed. **50 of 54 live result JSONs are CRLF and all 60 `write_text` sites lack `newline="\n"`.**
Rule: compare results **parsed, never byte-wise**, across platforms. Pin `lineterminator="\n"` on `to_csv` and `newline="\n"` on `write_text` in any script you touch — do not mass-edit all 60, because that restamps every producer hash and marks all 53 results stale at once. A reproducibility claim established on one OS is not established until it is re-run on the other.

## Standing traps that are not failures of a single run
- **Post-hoc catalogue substitution.** Swapping `primary` (43) for `union` (47) to raise n is the practice that produced four incompatible catalogues in the superseded project. `load_catalogue(which)` is the only permitted event source; inline date lists are forbidden.
- **Guards that compare the wrong thing.** The first SNAPSI corruption guard compared members by *label* and passed NRL, whose members differ while the ensemble mean is identically zero. Test the effect, not the labels.
- **Automated verdicts printed by scripts.** `within_model_check.py` prints "Headline stands" from the wrong criterion (`within > 0.3×pooled` instead of `within − pseudo_within`). Read the table, not the verdict line.
